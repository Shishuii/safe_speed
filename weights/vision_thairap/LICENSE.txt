What the files contain
  thairap_probes.npz: 11 logistic-regression probes (coefficients, intercepts,
  iRAP class codes and short iRAP category names) that map a CLIP ViT-L/14 image
  embedding to an iRAP road attribute code: street lighting, paved shoulder (both
  sides), roadside severity distance and object (both sides), skid resistance,
  traffic calming, property access and service road. They were fitted by the
  SafeSpeed team on CLIP embeddings of the 2,037 ThaiRAP survey images, with the
  ThaiRAP ground truth distributed with V-RoAst as labels.

  dinov3_heads.npz: the DINOv3 ThaiRAP classifier. One linear softmax head per
  ThaiRAP attribute that varies in the labels (weights, biases, the input
  standardisation, iRAP class codes and each attribute's role), on frozen
  DINOv3 ViT-L/16 image features. Trained by the SafeSpeed team on the same
  ThaiRAP images and labels, mirrored images with driver/passenger-side labels
  swapped included. Only the design-role attributes are model inputs (the
  ensemble member gbm_c2g_vision_irap); the reference-role heads are kept for
  completeness.

  No ThaiRAP image, label table or V-RoAst prompt text is included.

Using the package without these weights
  The DINOv3 classifier is optional: without dinov3_heads.npz everything else
  runs. Only `python run_vision.py --with-dinov3` (the a_* columns) and
  `python run_ensemble.py --stack with_dinov3` use it.
  Without the whole folder the vision model does not run. The design-speed
  model (`python run_inference.py`) does not use it, and
  `python run_ensemble.py --stack without_images` runs the ensemble without any
  image member.
